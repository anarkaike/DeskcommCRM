O servidor MCP externo agora pode assinar operações de gravação com uma chave HMAC separada do token de acesso. Configure a mesma chave no WordPress e no DeskcommCRM para habilitar gravações autorizadas; sem ela, consultas continuam disponíveis e as alterações ficam bloqueadas.
